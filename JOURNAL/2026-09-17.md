**Day-08**

* Today I continued practicing C programming and learned about memory, memory addresses, and pointers.

* I learned that variables are stored in memory and that & can be used to get the memory address of a variable, while * can be used to access the value stored at an address.

* I practiced creating a pointer to a battery variable and using the pointer to change the original battery value.

* I learned how pointers can be passed to functions so that the function can directly modify the original variable. I used this to create a drain_battery function that decreases the battery level.

* I also learned how pointers work with arrays. I practiced using pointer arithmetic to access different elements of an array, such as *(ptr + 1) for the second element.

* I combined arrays, pointers, and functions in a final exercise where I modified a sensor value through a pointer.

* This helped me understand why memory and pointers are important in C and how they can be useful for robotics and embedded systems where software needs to work directly with stored data.
