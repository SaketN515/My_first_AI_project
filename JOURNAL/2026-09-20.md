**Day-10**

* Today I continued my C programming practice and focused on using structs, pointers, and function-based logic to model a robot system more realistically.

* I created a program with a Robot struct that stored the battery level, speed, status, and detection flag, and used a global instance to represent the robot in the program.

* I practiced passing the struct to functions by pointer so the functions could change the original data instead of working on copies.

* I used a decide function to update the robot's status based on the battery and whether a person was detected. If the battery was low, the robot changed to Charging; if a person was detected, it changed to Following; otherwise it stayed Working.

* I also wrote a drain_battery function that decreased the battery and prevented it from dropping below zero.

* I used show_status to print the sensor values and confirm that the struct changed correctly after each operation.

* This exercise helped me understand how real embedded programs often use data structures and functions together to make decisions and update system state.

* I can now see how important it is to manage memory and values carefully when writing control logic, especially in robotics and automation systems.
