**Day-06**

* Today I practiced using a dictionary to store information about a robot, including its battery level, location, sensors, known people, and the person it can currently see.

* I learned how to access nested dictionary values, such as the camera setting inside the robot's sensors, and how to access individual coordinates from a location tuple.

* I used `if`, `elif`, and `else` statements to help the robot make decisions: warn when its battery is low, recognise a known person, or say when it does not know someone.

* I used a set for `known_people` and checked whether the detected person was in that set. This is useful for simple recognition logic in an AI or robot project.

* I created a `calculate_age` function with a default current year of 2026, then used it to calculate an age from a birth year.

* I also started a `response_robot` function that returns a different message based on the robot's mood. This is a good example of using functions and conditions to give an AI agent different behaviours.
